# Licenses
ReactOS uses a wide variety of licenses in its source tree. Historically, most of ReactOS was developed under [GNU General Public License v2.0 or later](https://spdx.org/licenses/GPL-2.0-or-later.html). We no longer recommend using this license for new code contributions due to incompatibilities with other licenses and legal complications. For example, Apache-2.0 code cannot be linked or built with GPL-2.0 code without violating either license (see Apache-2.0 Condition 3, Condition 4(c), and GPL-2.0 Conditions 4, 5, 6).

# Approved Licenses
## Recommended Licenses
New code contributions should use the MIT license. Using the MIT license ensures your contributions don't get discarded because of future legal challenges or incompatible license terms.

- [MIT License](https://spdx.org/licenses/MIT.html)

There are other licenses that are similar in spirit to MIT. For simplicity however, we still recommend MIT for new code.

- [BSD Zero Clause License](https://spdx.org/licenses/0BSD.html)
- [BSD 1-Clause License](https://spdx.org/licenses/BSD-1-Clause.html)
- [BSD 2-Clause "Simplified" License](https://spdx.org/licenses/BSD-2-Clause.html)
- [BSD 3-Clause "New" or "Revised" License](https://spdx.org/licenses/BSD-3-Clause.html)
- [BSD 4-Clause "Original" or "Old" License](https://spdx.org/licenses/BSD-4-Clause.html)
- [Creative Commons Zero v1.0 Universal](https://spdx.org/licenses/CC0-1.0.html)
- [The Unlicense](https://spdx.org/licenses/Unlicense.html)

### Dual Licensing
If you are working on a part of ReactOS with a viral license, but still want your contributions to be licensed under MIT, consider dual licensing your contribution under MIT and the viral license.

While we have accepted contributions under some of these licenses in the past, we will not accept new contributions under these licenses.

# If Your License Isn’t Listed
If your license is not listed, please ask about it in our [official chat](https://chat.reactos.org/) or mention it in your pull request. Project maintainers will discuss the license and add it to either the approved or forbidden license list.
